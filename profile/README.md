We're [Nidhi](https://github.com/nidhibharani) and [Prakhar](https://github.com/prafiles): two friends with day jobs and a habit of turning “does this exist yet?” into a working project.

AER is where we make the things we'd like to use ourselves. Reading tools, music studios, meeting notes, voice experiments, and the infrastructure that keeps them running. The throughline is curiosity.

### Built for use. Shared for tinkering.

We make small things with care, in our spare time. Many run on your own device or server. Most are MIT licensed; each repository has its own license and credits. Hedwig builds on [MailFlow by @maathimself](https://github.com/maathimself/mailflow) and is AGPL-3.0 licensed.

Try something, tell us what broke, or make it better. Bug reports, thoughtful issues, and pull requests are welcome in the relevant repository. Start with its README for setup and requirements.
