# Team AER public organization profile

GitHub displays [`profile/README.md`](profile/README.md) on the [Team AER organization overview](https://github.com/Team-AER).

The profile uses Team AER's approved pink “a” logo and a custom banner in `profile/assets/`. Project links point to public source repositories and the product pages at [aer.app](https://aer.app/). Update the profile when public projects or their descriptions change; retain each project's license and upstream attribution.

This repository contains profile content only. It does not define organization-wide issue templates, workflows, or contribution policies.
